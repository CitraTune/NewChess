GATSBY ROUGE
Regular / Version 1.003 / Refined review build

All-capitals display font interpreted from the main red GREAT GATSBY
lettering in Jim's supplied theatrical poster reference.

INSTALL
Install GATSBY ROUGE.otf or GATSBY ROUGE.ttf. Choose one format.
Both typing cases display capitals. Includes A–Z, 0–9, ASCII punctuation,
common currency and typographic symbols, and extended Latin capitals.
247 glyphs / 407 encoded characters.

REPLACING AN EARLIER BUILD
Replace the earlier GATSBY ROUGE font, then restart your design app
if it continues to show the old outlines.

POSTER FORMS
The regular capitals have a common 700-unit height for reusable text.
To reproduce the original composition, enlarge and reposition G in your
design application. The long upper-right Y blade is available through
Stylistic Set 1 (ss01) or Stylistic Alternates (salt).
An editable extended Y SVG is included as well.

COLOR + STROKE
These are solid monochrome fonts. Apply color in your design application.
The red fill and black stroke in the proofs are external styling;
the font files do not contain a built-in black outline or color layers.

REFERENCE
The supplied image is 500 x 400 pixels and is named
The_Great_Gatsby_(1926)_Theatrical_Poster_Retouched.jpg.
The filename labels it 1926; this was not independently researched.
Exact poster edition, artist and lettering designer: NA.
The eight visible title letters inform the masters. Unshown characters
are original companion designs. The unrelated script and production-line
lettering are not part of this font.

CONTENTS
OTF, TTF, full alphabet and figures, specimen, source comparison,
alternate preview, editable SVGs, original reference and detail crops,
validation, provenance and reproducible drawing sources.

REBUILD
Dependencies: fonttools, skia-pathops, Pillow, uharfbuzz.
Run build.py, render.py and validate.py in Source in that order.
Proof captions use system Helvetica, never the font outlines.
